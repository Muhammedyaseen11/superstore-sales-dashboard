# Superstore Sales Dashboard (Excel)

## 📌 Overview
This project analyzes Superstore sales data using Excel. The goal was to design an interactive dashboard that highlights key performance indicators (KPIs) such as regional sales, category performance, and profit trends.

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Slicers
- Data Cleaning & Formatting

## 🔄 Workflow
1. Cleaned and formatted raw sales data
2. Built pivot tables to summarize KPIs
3. Added slicers for dynamic filtering (region, category, time)
4. Designed charts to visualize trends

## 📊 Key Insights
- Identified top-performing product categories and regions
- Visualized profit trends over time
- Enabled dynamic filtering for better decision-making
